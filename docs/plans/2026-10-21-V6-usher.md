## The allowlist rule

`usher.allowlist_from_pack(pack) -> frozenset[str]` is `FIXED_ROUTES = ('/skills', '/experience', '/about',
'/contact', '/')` plus `/projects/<slug>` for each `(slug: <slug>)` on a line starting `Source: ` (slug
`[a-z0-9][a-z0-9-]*`). It is built once per session from `load_pack()` (read once per process). An href is on the
list only by exact string match: no normalising, so `/projects/agent-harness/`, `/admin`, `https://evil.test` and
`/projects/agent-harness?x=1` are all off it.

## NavigatePayload

`concierge/contract.py`: `NAVIGATE_TOPIC = "concierge.navigate"`, `NAVIGATE_MAX_BYTES = 1024`, and

```python
class NavigatePayload(BaseModel):
    model_config = ConfigDict(extra="forbid")
    href: str
    reason: str = Field(max_length=MAX_DETAIL)  # 120, the contract's one-short-sentence cap
    at: str  # iso_utc(now_ms()), as every other time in the contract (D13)
```

`tests/contract/navigate.schema.json` is the page's view: `href` matches
`^(/projects/[a-z0-9][a-z0-9-]*|/skills|/experience|/about|/contact|/)$`, `reason` a string of at most 120,
`at` the contract's ISO pattern, no other keys. A body is at most 1024 UTF-8 bytes; the Usher checks before it sends
(with a 120-character reason and an allowlisted href a body is about 200 bytes, so the check is a backstop).

## The rate limit

`NAVIGATE_MIN_INTERVAL_S = 8.0`, the page's own limit mirrored (§2: "never more than once per 8 s"). Per `Usher`, so
per session; on the Usher's `clock` (`time.monotonic` in the session, a fake in tests). The slot is taken before the
send is awaited, so two tool calls in the same turn (parallel tool calls) send once; a failed send gives the slot
back. Refusals don't take it.

## The tool and its replies

`ConciergeAgent.show_page(href: str, reason: str) -> str` forwards to `Usher.show_page`. In order:

1. href off the allowlist: journal `navigate_refused` with `{"path": <urlsplit(href).path, at most 120 chars>}` (no
   reason text, no query, no host; `""` unless it is a site path of a plain or http(s) href that passes the write gate,
   so `mailto:`/`tel:`/`javascript:` payloads never reach the journal; each distinct path once per session), no
   publish, reply **`That page is not one I can show`**.
2. within 8 s of the last send: no publish, reply **`Already showing a page; keep talking`**.
3. the reason: stripped, cut to 120 characters, then `gate.check_text`. One that fails is not sent: the body carries
   `reason: ""` and the navigation still goes (the page names the destination from the href itself). D23 (a).
4. publish on `concierge.navigate` with `publish(room, topic, payload)`; reply **`Showing them <href>`**.
5. a send that raises (`StreamError`, a room that never connected) or takes over `SEND_TIMEOUT_S = 2.0`: logged by
   type, the slot given back (unless a later send has taken it), reply **`That page didn't open; keep talking`**.

A session without a room or an Usher (the capped session, the conversation evals, tests) answers `That page is not one
I can show`. `navigate_refused` joins `JournalType`. The journal is the session's `journal_row` partial (on the
writer's thread); a session without memory has no thread, so nothing is journaled there.

The tool is a visitor-asked path like `remember`: it runs inside the LLM's tool execution, not in a
`conversation_item_added` handler or `on_user_turn_completed`, so `tests/test_critical_path.py` is unchanged.

  is journaled once per session; `load_pack()` is called once in `session.py`; the plan's `MAX_REASON` now reads
  `MAX_DETAIL`. New tests: the real allowlist checked against the schema, a FakeLLM tool call, and a session without
  a store.
- **Minor, recorded rather than changed:** a gate-rejected reason isn't journaled (D23 (a)); the fifth reply is
  D23 (f). `contract.py` (249 lines) and `session.py` (249) sit at the 250 limit, so V6-02 should not add lines to

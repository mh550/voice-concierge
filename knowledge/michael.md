## Project: Agent Harness: overnight software delivery with verification gates
Source: projects.ts

Personal and open source (https://github.com/mh550/agent-harness), Sep – Oct 2026; Michael is designer and operator. A
driver that runs coding agents overnight, one fresh session per feature, and merges only work an independent session
has verified. On Oct 17 it ran two projects: 71 features planned, 55 passing, 52 verified and merged through 12 PRs,
and 374 tests added, for $139.34 in total, about $2.53 per passing feature. Claude Code agents wrote much of the code
under his direction.

## Project: Linear Adoption + Agentic Bug Workflow
Source: projects.ts

At MAXX Potential. QA ran on per-person Google Sheets with no status history. He moved the team to Linear, chosen partly for
its MCP server, and wired it into the lead engineer's Claude Code workflow, so filing and triage became automated:

## Project: Self-hosted music library & DJ crate pipeline
Source: projects.ts

Personal, on a home server (https://github.com/mh550/dj-crate-streaming), Sep – Oct 2026. A music library he hosts at
